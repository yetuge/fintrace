# Microsoft FY2024 收入核对

这是公开财报的人工整理案例。前端执行确定性计算，流程步骤用于展示设计，不代表 Agent 已执行实时取证。

## 研究问题与范围

微软 FY2024 总收入同比增长多少？Intelligent Cloud 是否是主要收入增量来源？业绩公告中的约 16% 与约 15% 能否同时成立？

采用 FY2024 业绩发布时的原始披露，金额统一为百万美元；年度比较采用截至各年 6 月 30 日的十二个月，分部不混用后续重分类数据。整理日期为 2026-09-30，不作为资料实际拉取时间。

## 输入与复算

| 指标，百万美元             |  FY2024 |  FY2023 |
| -------------------------- | ------: | ------: |
| 全年总收入                 | 245,122 | 211,915 |
| Intelligent Cloud 全年收入 | 105,362 |  87,907 |
| 第四财季总收入             |  64,727 |  56,189 |

- 全年增量：`245122 - 211915 = 33207`。
- 全年同比：`33207 / 211915 × 100% ≈ 15.67%`。
- 分部增量：`105362 - 87907 = 17455`。
- 分部占总增量比例：`17455 / 33207 × 100% ≈ 52.56%`。
- 第四财季同比：`(64727 - 56189) / 56189 × 100% ≈ 15.20%`。

全年已报告增速约 16%；第四财季已报告增速约 15%；全年固定汇率增速也约 15%。比较时必须同时匹配期间、指标、汇率基础和报告版本。52.56% 是分部增量占比，不能表述为 AI 收入贡献。

当前测试验证案例的复算结果、引用关联、导出时保留待补证项，以及展示路由不预加载聊天模块。浏览器验证覆盖视图切换、结论详情、筛选与空状态、复核标记、下载及移动端布局。

金融 Adapter、来源拉取状态、自动口径校验、证据写入 Memory 和真实 Agent Trace 尚未接入。这些后续工作需要分别留存真实输入、工具调用、输出与断言，才能声称金融研究闭环已运行。
