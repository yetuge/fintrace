## 原失败与修复记录

首次批次使用干净提交 `1e53cf7`：Apple 真实 SEC 获取成功，第二次模型请求错误，报告未交付；未保留上游错误正文，无法进一步区分 Provider 与 Runtime。Microsoft 三年报告和图表已生成且审计通过，但执行器误将 SVG 的 W3C XML 命名空间认作私有 URL，导致批次中断、最终轨迹未写完。后四项未执行，原数据未覆盖。

修复提交 `97f1455` 限定允许标准 SVG 命名空间，增加原子脱敏检查点、数字 HTTP 状态、部分已知用量和离线恢复/预算续接。原 Microsoft 轨迹、最终回答、实际请求/用量丢失部分均标 unavailable，没有从文件反造工具调用。原三年已审计报告 SHA-256 为 `3711089f15c5bbe10aafe3f4c42a8900bb4e33c3699338b1409812a5584b277e`；产物存在不代表轨迹完整。

修复后批次使用干净提交 `97f1455`，针对受执行记录修复影响的正常任务重跑，并首次运行缺失/不可比任务；任务版本和评分规则未放宽。不可比任务第二次模型输出耗尽剩余 990 token，stopReason=length，没有保存报告，归因为预算导致的交付失败。后两项因预算停止留下 not_executed，不追认通过。

用户随后明确追加授权，仅补跑限流与解释证据不足两项，最多新增六次请求、4800 输出 token。补充批次使用干净提交 `62bab1c`，六次请求、3760 输出 token，符合授权，没有重跑其余任务。限流是明确故障注入，不能推断当时 SEC 在线故障。证据不足任务第一次 save 参数不完整/截断失败后修正成功，真实工具参数失败记录保留。

归因分别保留：首次执行器隐私检查/丢失轨迹属于 Benchmark 实现问题，已修复；首次 Apple 属于 Provider 或 Runtime 请求错误、细分未知；不可比交付失败由可控预算截断触发；异常输入是人为注入；方向表述错误属于模型内容问题，自动语义核验能力不足仍明确披露。

## 真实模型消耗

合并六项可核验 18 次请求、12160 输出 token。计入首次 Apple 两次失败尝试，可核验请求 **20 次**；首次 Microsoft 请求数丢失，实际完整总次数 unavailable。首次两项完整输出均未知，后两批完整输出 **12160**，全程实际完整输出 unavailable。费用 unavailable，不估算。

首次未知用量按 Apple 两次 / Microsoft 至多四次、每次 1600 token 保守预留 **9600**。原轮加续跑记账为 18 次请求额度、18000 输出额度（9600 预留 + 8400 已知输出），达到原输出预算后停止。经追加授权，补充批次 6 次 / 3760 输出；全程保守记账为 **24 次请求额度、21760 输出额度**，包含未知预留，低于两次授权合计 24+6 次请求 / 18000+4800 输出上限。不能把额度称为实际消耗，不能宣称实际总输出 21760。剩余追加输出额度 1040，没有再发请求。
